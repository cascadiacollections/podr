# Trademark and branding policy

The source code in this repository is free software (see [LICENSE](LICENSE)). This policy
covers what the code license does **not** grant: the project's identity.

## What is reserved

- The name **"Podr"** as the name of an app, website, or distributed product
- The Podr app icon (the favicon, touch, and maskable icons in `assets/`) and any other project
  logos or artwork
- The domain `podrapp.com`

These remain the property of Kevin T. Coughlin and may not be used to name, brand, or market a
fork or derived product without written permission.

## What you can do freely

- Fork, modify, build, self-host, and redistribute the code under its license —
  **under a different name, icon, and domain**
- Build and run the app from source for yourself, unchanged, including its name and icon
- Self-host an unmodified build, as [docs/SELF_HOSTING.md](docs/SELF_HOSTING.md) describes, as
  long as it isn't presented as the official podrapp.com
- Use the name "Podr" nominatively: to refer to this project in articles, reviews,
  compatibility notes ("based on Podr"), and attribution

## Why

This is the standard FOSS arrangement (used by Firefox, VLC, and many others): the code is free,
the identity is not. It protects users from confusing or misleading clones without restricting
any freedom the license grants.
